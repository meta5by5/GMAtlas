# Saga Atlas Design Constitution

# Pack 72 --- Campaign Cognition Model

## Purpose

This document defines the mental model Saga Atlas should support while a
Game Master is actively running a session.

## Cognitive Cycle

A Game Master continuously repeats:

Notice

↓

Understand

↓

Choose

↓

Resolve

↓

Remember

Saga Atlas should reinforce each stage.

## Notice

Surface only information that is immediately relevant.

Examples:

-   Active threats
-   Current objective
-   Nearby NPCs
-   Pending timers
-   Story recommendations

## Understand

Context should answer:

-   What is happening?
-   Why does it matter?
-   What changed?
-   What is connected?

## Choose

Present a small number of meaningful actions instead of exhaustive
option lists.

Examples:

-   Continue Story
-   Reveal Clue
-   Travel
-   Negotiate

## Resolve

Provide the correct rules lens, dice tools, references, and oracles with
minimal searching.

## Remember

Automatically preserve:

-   Outcomes
-   Relationships
-   Discoveries
-   Consequences
-   Time progression

## Cognitive Load Rules

Reduce:

-   Searching
-   Re-entering data
-   Remembering hidden state
-   Navigating between screens

Increase:

-   Context
-   Confidence
-   Flow
-   Story awareness

## Acceptance Criteria

Every interaction should support the Game Master's natural thinking
process rather than forcing the Game Master to think like the software.
