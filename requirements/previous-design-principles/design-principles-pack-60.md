# Saga Atlas Design Constitution

# Pack 60 --- Final Stewardship, Guiding Questions & Design Legacy

## Purpose

This final extension establishes the questions that should continuously
guide Saga Atlas long after the original designers have moved on.

## The Seven Guiding Questions

Before implementing any change, ask:

1.  Does this help the Game Master tell a better story?
2.  Does this reduce cognitive effort?
3.  Does this preserve campaign continuity?
4.  Does this strengthen Mission Control?
5.  Does this reuse existing architecture?
6.  Can the feature be explained in one sentence?
7.  Will this still feel correct ten years from now?

If several answers are "no", redesign before implementation.

## Stewardship

Every contributor becomes a steward of the Campaign Operating System.

Protect:

-   Simplicity
-   Continuity
-   Context
-   Trust
-   Extensibility
-   User ownership

## Legacy Principle

The codebase will evolve.

The framework will evolve.

The interface will evolve.

The Constitution should remain the stable compass that explains *why*
Saga Atlas exists.

## Final Success Metric

The highest compliment is not:

"This software has many features."

It is:

"This software helped me run my best campaign."

## End of Constitution

This concludes the initial Design Constitution series.

Future additions should extend these principles through new
Architectural Decision Records, engine documentation, and implementation
guides rather than replacing them.
