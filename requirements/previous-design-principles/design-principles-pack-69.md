# Saga Atlas Design Constitution

# Pack 69 --- Accessibility, Inclusivity & Universal Usability

## Purpose

This document establishes accessibility and usability principles so Saga
Atlas remains comfortable to use during long tabletop sessions by a wide
range of players and Game Masters.

## Design Philosophy

Accessibility is a core design requirement, not a post-release
enhancement.

Good accessibility also improves usability for everyone.

## Visual Design

Mission Control should provide:

-   High-contrast themes
-   Scalable typography
-   Adjustable density
-   Color-independent status indicators
-   Keyboard-visible focus states

## Interaction

Every major workflow should be possible with:

-   Mouse
-   Keyboard
-   Touch

Avoid interactions that depend solely on drag-and-drop. Provide
equivalent context menu actions.

## Information Design

Recommendations should be:

-   Concise
-   Clearly prioritized
-   Grouped by intent
-   Free of unnecessary jargon

## Cognitive Accessibility

Reduce memory burden by:

-   Keeping context visible
-   Using progressive disclosure
-   Avoiding modal overload
-   Explaining recommendations
-   Remembering user preferences

## Internationalization

Design for:

-   Localized text
-   Variable string lengths
-   Unicode support
-   Date/time localization
-   Metric and imperial units where appropriate

## Acceptance Criteria

-   Primary workflows remain accessible without a mouse.
-   UI adapts to different display sizes and accessibility preferences.
-   Accessibility improvements reinforce Frictionless Empowerment rather
    than competing with it.

## Closing Principle

The best interface is one that allows every Game Master to focus on the
story rather than the software, regardless of how they interact with the
application.
