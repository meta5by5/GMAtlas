# Saga Atlas Design Constitution

# Pack 14 --- UI Components, Drawers & Interaction Standards

## Purpose

The user interface exists to support thinking, not data entry.

Every component should reinforce Frictionless Empowerment by reducing
cognitive load while keeping the GM in control.

## Three Visual Tiers

### Tier 1 --- Primary

Always visible:

-   Mission Control
-   Context Strip (WHO / WHERE / WHAT / WHY / HOW)
-   Active Workspace

### Tier 2 --- Secondary

Context-sensitive support:

-   Story Actions
-   Campaign State
-   Co-Pilot
-   Timeline

### Tier 3 --- Background

Reference material:

-   Journal
-   Oracles
-   Entity Inspector
-   Relationship Graph
-   PDFs
-   Settings

These appear as drawers.

## Drawers

Drawers slide over the workspace without replacing it.

Requirements:

-   Edge tabs always visible.
-   One-click open/close.
-   Remember width.
-   Support side-by-side drawers.
-   Never navigate away from Mission Control.

Suggested right-side tabs:

-   Journal
-   Oracle
-   Inspector
-   Graph
-   PDFs
-   Settings

Suggested left-side tabs:

-   Groups
-   Library
-   Assets
-   Search

## Context Cards

WHO, WHERE, WHAT, WHY and HOW remain visible at all times.

Each card displays:

-   Current selection
-   Relationship counts
-   Status indicators
-   Quick edit

Clicking a card changes the active workspace rather than navigating.

## Story Actions

Story Actions are the primary controls.

Buttons should use action verbs:

-   Continue
-   Reveal
-   Suggest
-   Observe
-   Resolve
-   Advance
-   Travel
-   Shift Story

Avoid generic labels like "Edit" or "Generate" where a narrative verb is
clearer.

## Co-Pilot

Always visible.

Shows:

-   Observation
-   Recommendation
-   Consequence
-   Opportunity
-   Suggested Oracle

Recommendations include confidence and rationale.

## Dice Panel

Docked bottom-right.

Requirements:

-   Minimized by default.
-   Expandable history.
-   Context-aware labels.
-   Append results to Journal.
-   Link rolls to entities, scenes and missions.

## Responsive Layout

Mission Control should remain usable on:

-   Desktop
-   Laptop
-   Tablet
-   Portrait mode

Progressive disclosure replaces scrolling wherever practical.

## Acceptance Criteria

-   A GM can run a full session without leaving Mission Control.
-   Navigation is replaced by contextual interaction.
-   Drawers never obscure critical story information.
-   The interface prioritizes current decisions over editing tools.
