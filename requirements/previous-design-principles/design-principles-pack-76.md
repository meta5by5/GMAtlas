# Saga Atlas Design Constitution

# Pack 76 --- Campaign Memory & Narrative Continuity

## Purpose

This document defines how Saga Atlas should preserve long-term narrative
continuity across months or years of play.

## Philosophy

Campaigns are remembered through accumulated context, not isolated
session notes.

The application should function as a persistent memory that strengthens
continuity over time.

## Memory Layers

### Immediate Memory

Current scene:

-   Participants
-   Objectives
-   Threats
-   Recent events

### Session Memory

Current session:

-   Discoveries
-   Decisions
-   Rolls
-   New relationships
-   Outstanding questions

### Campaign Memory

Persistent history:

-   Major events
-   Recurring NPCs
-   Faction evolution
-   Reputation
-   World changes
-   Promises made
-   Debts owed

## Narrative Recall

At the start of each session Saga Atlas should summarize:

-   What happened last time
-   Unresolved threads
-   Active objectives
-   Relevant NPCs
-   Pending consequences
-   Recommended next actions

## Memory Weight

Not all events are equally important.

Significance should increase with:

-   Story impact
-   Relationship changes
-   Campaign milestones
-   Repeated references
-   GM pinning

Higher-weight memories should appear more often in recommendations.

## Continuity Checks

The Story Engine should detect:

-   Forgotten plot threads
-   Contradictory facts
-   Missing consequences
-   Long-idle factions
-   Unresolved promises

These become observations, never automatic corrections.

## Acceptance Criteria

-   Campaigns remain easy to resume after long breaks.
-   Important narrative history is surfaced automatically.
-   Memory strengthens recommendations without overwhelming the GM.
-   Story continuity improves naturally as the campaign grows.
