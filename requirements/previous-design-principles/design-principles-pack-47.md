# Saga Atlas Design Constitution

# Pack 47 --- Road to Saga Atlas 2.0

## Purpose

This document describes the transition from the current prototype to the
long-term architecture.

## Phase 1 --- Stabilize

Objectives:

-   Complete Storage Kernel
-   Remove duplicate state
-   Replace polling with Event Bus
-   Unify campaign schema

## Phase 2 --- Simplify

Objectives:

-   Mission Control as the only primary workspace
-   Replace feature navigation with contextual workspaces
-   Complete drawer architecture

## Phase 3 --- Connect

Objectives:

-   Full Context Graph
-   Relationship-first editing
-   Universal Search
-   PDF integration

## Phase 4 --- Assist

Objectives:

-   Campaign Intelligence Engine
-   Decision Engine
-   Explainable recommendations
-   Living campaign memory

## Phase 5 --- Expand

Objectives:

-   Plugin SDK
-   Community ecosystem
-   Multi-device sync
-   Foundry integration
-   Mobile companion

## Architectural Promise

Future versions should require less user effort while providing greater
context, continuity, and creative support.

## Success

The project reaches its vision when Mission Control becomes the natural
place to run every tabletop campaign regardless of genre or rules
system.
