# Saga Atlas Design Constitution

# Pack 71 --- The First Principles of Campaign Design

## Purpose

This document captures the fundamental truths from which every Saga
Atlas feature should be derived.

Rather than describing implementation, it defines the assumptions that
make the platform valuable.

## First Principles

### A campaign is a living system.

A campaign changes every session through player decisions, consequences,
discoveries, and the passage of time.

### Information gains value through relationships.

An NPC with no connections is merely a note.

An NPC connected to missions, factions, locations, journals, and
promises becomes meaningful.

### The Game Master's attention is finite.

Every unnecessary click, search, dialog, or repeated decision consumes
attention that should instead be spent on storytelling.

### Story continuity is the highest form of quality.

Players remember consistency more than mechanics.

The software should therefore prioritize remembering context over
remembering rules.

### Mechanics are replaceable.

Story survives changes in rules systems.

The architecture should reflect this truth.

### Discovery is more satisfying than exposition.

Recommendations should reveal opportunities rather than narrate
outcomes.

## Design Implications

Therefore Saga Atlas should:

-   infer before asking,
-   connect before duplicating,
-   recommend before searching,
-   preserve before replacing,
-   simplify before expanding.

## Acceptance Criteria

Every future feature can be justified by one or more of these first
principles.

Features that cannot be traced back to a first principle should be
reconsidered before implementation.
