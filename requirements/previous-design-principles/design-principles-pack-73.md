# Saga Atlas Design Constitution

# Pack 73 --- Information Architecture & Progressive Disclosure

## Purpose

This document defines how information should be organized and revealed
so the Game Master is never overwhelmed.

## Principle

Show only what is needed now.

Everything else should remain one interaction away.

## Levels of Information

### Level 1 --- Immediate

Always visible:

-   Current Story
-   Current Objective
-   WHO / WHAT / WHERE / WHY / HOW
-   Primary Story Actions

### Level 2 --- Context

Available through drawers:

-   Journal
-   Inspector
-   Oracle
-   PDFs
-   Timeline
-   Graph

### Level 3 --- Deep Reference

Opened only when requested:

-   Full editors
-   Historical revisions
-   Detailed statistics
-   Plugin configuration

## Progressive Disclosure Rules

-   Prefer summaries over full records.
-   Expand inline before opening dialogs.
-   Use drawers before navigation.
-   Preserve context while revealing detail.

## Context Persistence

Changing focus should not erase previous context.

Breadcrumbs and history allow rapid return.

## Acceptance Criteria

-   The interface remains calm even for very large campaigns.
-   Information density adapts to the current task.
-   The GM rarely feels lost or overwhelmed.
