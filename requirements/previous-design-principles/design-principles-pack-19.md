# Saga Atlas Design Constitution

# Pack 19 --- Oracle Engine, Recommendation System & Discovery

## Purpose

The Oracle Engine transforms random tables into context-aware creative
assistants.

Randomness is preserved, but guided by campaign state.

## Philosophy

Oracles should stimulate creativity, not replace it.

The engine recommends relevant tables automatically while allowing the
GM to roll any oracle manually.

## Oracle Sources

Oracle content may originate from:

-   Built-in tables
-   Imported tables
-   Rules plugins
-   PDF indexes
-   Community packages

All oracle collections expose metadata rather than UI.

## Metadata

Each oracle declares:

-   Category
-   Genre
-   Tags
-   Supported Activities
-   Supported Rules Lenses
-   Confidence Weight
-   Story Phase

## Recommendation Pipeline

Current Context

↓

Context Graph

↓

Story Engine

↓

Oracle Weighting

↓

Recommended Oracles

Recommendations are explainable.

## Oracle Weighting

Weights consider:

-   Current activity
-   Current location
-   Story momentum
-   Active threads
-   Danger
-   Hope
-   Nearby entities
-   Recent oracle usage

Frequently repeated tables are naturally deprioritized.

## Discovery

Discovery should feel earned.

The engine prefers:

-   Clues
-   Opportunities
-   Environmental storytelling
-   NPC observations
-   Emerging consequences

before dramatic twists.

## Manual Rolling

The GM can always search and roll any oracle.

Manual selections update recommendation history but never disable future
suggestions.

## Oracle Results

Each result may be:

-   Accepted
-   Edited
-   Ignored
-   Saved as Inspiration

Accepted results become linked entities in campaign history.

## Acceptance Criteria

-   Recommendations reduce table hunting.
-   Randomness remains available.
-   Oracle history avoids repetition.
-   Oracle results strengthen campaign continuity.
