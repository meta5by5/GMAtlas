# Saga Atlas Design Constitution

# Pack 29 --- UX Heuristics, Wireframe Rules & Screen Composition

## Purpose

This document captures layout rules that should remain consistent across
every workspace.

## The Five-Question Layout

Every primary workflow should answer, in order:

1.  WHO
2.  WHAT
3.  WHERE
4.  WHY
5.  HOW

The current question owns the center workspace.

## Screen Composition

Top: - Mission title - Breadcrumbs - Continue Story

Left: - Story context - Current selections

Center: - Active workspace - Editable information

Right: - Co-Pilot - Recommendations - Story actions

Drawers: - Journal - Oracle - Inspector - PDFs - Graph

## Cognitive Load Rules

-   Prefer one screen over scrolling.
-   Prefer drawers over navigation.
-   Prefer actions over forms.
-   Prefer relationships over duplicate fields.
-   Prefer context over configuration.

## Visual Hierarchy

Primary: Current decision.

Secondary: Supporting information.

Tertiary: Reference material.

## Editing

Inline editing is preferred.

Dialogs are reserved for creation, deletion, or complex relationship
editing.

## Buttons

Buttons should use verbs.

Good: - Continue Story - Reveal Clue - Shift Story - Advance Time

Avoid: - Edit - Manage - Configure

## Acceptance Criteria

A first-time GM should understand what to do within thirty seconds
without reading documentation.
