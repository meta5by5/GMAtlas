# Saga Atlas Design Constitution

# Pack 23 --- Knowledge Graph, Search & Unified Discovery

## Purpose

Saga Atlas should allow the Game Master to discover information rather
than remember where it was stored.

The Knowledge Graph unifies entities, journal entries, rulebooks,
oracles, maps, PDFs, and campaign state into a single searchable
network.

## Philosophy

The GM searches for concepts.

Saga Atlas locates information.

The user should never need to remember which module contains the answer.

## Universal Search

Searching should return a blended result list.

Possible result types:

-   Characters
-   NPCs
-   Groups
-   Ships
-   Vehicles
-   Colonies
-   Locations
-   Missions
-   Threads
-   Assets
-   Lifeforms
-   Journal Entries
-   Oracle Tables
-   Oracle Results
-   PDFs
-   PDF Pages
-   Rules
-   Dice Rolls
-   Story Actions

## Ranking

Results are ranked by:

-   Current campaign context
-   Relationship proximity
-   Story importance
-   Recent usage
-   User pins
-   Tags
-   Confidence score

The most relevant information appears first.

## Knowledge Cards

Every result opens a contextual card.

The card summarizes:

-   Title
-   Entity type
-   Relationships
-   Recent activity
-   Story relevance
-   Related documents
-   Quick actions

The full editor remains one click away.

## Saved Views

The GM may create persistent views.

Examples:

-   Current Expedition
-   Corporate Conspiracy
-   Alien Biology
-   Active Colonies
-   All Open Threads

Views are dynamic queries rather than static folders.

## Cross-Linking

Knowledge items should reference each other.

Example:

Journal Entry → NPC → Mission → Colony → Planet → PDF page → Oracle
Result

The graph allows movement between related concepts without navigating
modules.

## Discovery

The Knowledge Graph enables discovery through relationships.

Examples:

-   "Show everything connected to Hadley's Hope."
-   "Show unresolved threads involving Company Security."
-   "Find all references to xenobiology."

The result is a graph, not a list.

## Acceptance Criteria

-   One search box replaces multiple search tools.
-   Relationships improve discovery automatically.
-   Search results adapt to current campaign context.
-   The Knowledge Graph becomes the primary navigation system for
    reference material.
