# Saga Atlas Design Constitution

# Pack 39 --- Campaign Operating System Maturity Model

## Purpose

This document defines the maturity roadmap for Saga Atlas as it evolves
from a campaign manager into a full Campaign Operating System (COS).

## Maturity Levels

### Level 0 --- Repository

Characteristics:

-   Static data
-   Manual organization
-   No contextual awareness

Examples: - Notes - JSON - PDFs

------------------------------------------------------------------------

### Level 1 --- Organizer

Capabilities:

-   Entity management
-   Journal
-   Relationships
-   Templates

The application remembers information.

------------------------------------------------------------------------

### Level 2 --- Assistant

Capabilities:

-   Story recommendations
-   Oracle suggestions
-   Rules lens recommendations
-   Campaign Director

The application understands context.

------------------------------------------------------------------------

### Level 3 --- Co‑Pilot

Capabilities:

-   Campaign Intelligence Engine
-   Story Engine
-   Decision Engine
-   Context Graph

The application anticipates needs.

------------------------------------------------------------------------

### Level 4 --- Campaign Operating System

Capabilities:

-   Living World
-   Dynamic factions
-   Unified knowledge graph
-   Federated workspaces
-   Integrated reference ecosystem

The application coordinates the campaign.

------------------------------------------------------------------------

### Level 5 --- Creative Partner

Capabilities:

-   Long-term campaign memory
-   Explainable AI recommendations
-   Predictive story guidance
-   Personalized workflows
-   Adaptive interfaces

The application continuously improves the GM experience while preserving
complete creative authority.

## Measuring Progress

Each release should improve at least one of:

-   Reduced preparation time
-   Reduced navigation
-   Increased context awareness
-   Better continuity
-   Faster retrieval of information
-   Better recommendations
-   Simpler workflows

## Architectural Rule

Advancing to a higher maturity level must not require abandoning earlier
campaigns.

Backward compatibility and migration remain mandatory.

## Acceptance Criteria

-   Maturity is measured by the quality of the GM experience rather than
    the number of implemented features.
-   Every architectural improvement should move Saga Atlas closer to
    becoming a true Campaign Operating System.
